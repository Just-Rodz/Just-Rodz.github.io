STEP 01

CREATE REPO ON GITHUB

Go to github.com/new. Name it exactly Just-Rodz.github.io for your top-level user website, or any repo name for a project site.

STEP 02

PUSH OR UPLOAD FILES

Push via terminal commands above, or drag and drop all files directly via GitHub's web interface ("Add file" → "Upload files").

STEP 03

ENABLE GITHUB PAGES

Under Settings → Pages, set Source to Deploy from a branch, Branch to main, and Folder to /(root).

STEP 04

LIVE AT JUST-RODZ.GITHUB.IO

GitHub actions will build and deploy the static site in ~60 seconds. Accessible worldwide with HTTPS encryption.
